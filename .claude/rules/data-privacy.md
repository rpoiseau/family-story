# Données et confidentialité

- Le site GitHub Pages est public : considérer tout fichier livré comme publiquement accessible.
- Toutes les informations familiales réelles doivent être pseudonymisées.
- Aucun mineur ne doit être présenté.
- Ne stocker aucune adresse, coordonnée privée, donnée médicale ou financière, identifiant secret ou date de naissance complète.
- N'intégrer un portrait ou une image réelle qu'après validation explicite.
- Ne jamais placer d'information personnelle réelle dans les exemples, tests, données fictives, noms de fichiers, messages de commit ou `PROGRESS.md`.
- Ne jamais inventer de fait familial.
- Pour les emplacements temporaires, utiliser uniquement `Lorem ipsum` et des identifiants génériques.
- Les données éditoriales sont stockées dans des JSON locaux et accompagnées de types TypeScript.
- Les images validées sont stockées dans le dépôt.
